# Projet – Pattes & Cie

Ce projet consiste à réaliser une interface web permettant de consulter le carnet de santé digitalisé des animaux d’une clinique vétérinaire. Il est basé sur une maquette Figma et utilise des données mockées chargées depuis des fichiers JSON.

## 1. Objectifs du projet
* Structurer la donnée via : Use Cases, Dictionnaire de données, MCD.
* Fournir un JSON mocké cohérent avec le modèle conceptuel.
* Reproduire  la maquette fournie.
* Afficher dynamiquement les données : liste + fiche animal.
* Livrer le projet

## 2. Technologies utilisées

* **Next.js 14** – framework React utilisé pour structurer le projet
* **React** – logique des composants
* **JSON** – données mockées consommées côté client
* **GitHub Pages** – déploiement
